# Packarr branding

The mark combines a P, a stack of episode cards, and an amber check: selecting only
missing episodes from a pack. The wordmark reads **Packarr**.

Generated with the built-in image generation tool; no API key was used. Original
transparent PNG masters are in `assets/packarr-icon.png` and `assets/packarr-logo.png`.
Only transparent padding and export dimensions were normalized for app-store assets:

- `packarr/icon.png`: 256 × 256; `icon@2x.png`: 512 × 512.
- `packarr/logo.png`: 250 × 100; `logo@2x.png`: 500 × 200.

## Icon prompt

Use case: logo-brand. Create the finished standalone app icon for Packarr, a Home
Assistant helper that extracts only missing TV episodes from a torrent season pack.
A crisp memorable geometric mark: three compact episode cards or tiles stacked as
a package, the front tile visibly selected by a precise check mark, integrated into
a subtle letter P silhouette. Professional modern software identity, vector-like
clean geometry rendered as PNG, excellent small-size recognition. Restrained
teal/cyan with a small warm amber selection accent, strong balanced silhouette,
no gradients that obscure edges. Centered square composition with generous
transparent padding. Genuinely transparent background. No text, no wordmark,
no mockup, no shadows outside the mark, no extra logos, no watermark.

## Wordmark prompt

Use case: logo-brand. Produce the finished horizontal Packarr wordmark logo for the
Home Assistant app store and GitHub README using the supplied image as the existing
brand mark. Preserve the supplied dark teal P silhouette, three stacked episode
cards, bright cyan tones and amber check mark, with its visual identity intact.
Place a compact version of this mark at the left, followed by the exact word
"Packarr" in a clean confident rounded geometric sans serif, medium saturated teal
lettering readable on light and dark interfaces. One polished logo only, no captions
or other words. Wide horizontal composition approximately 3:1, tidy alignment,
balanced spacing and generous transparent padding. Genuinely transparent background.
No mockup, no backdrop, no watermark.
